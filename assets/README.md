# Logo files

LuauPilot logos (the file names stay, e.g. `luapilot.ico`; replace them with your own logos and keep the aspect of the sizes):

| File | Used for |
|---|---|
| `assets/logo-mark.png`, `assets/logo-wide.png`, `assets/logo-wide-dark.png` | source logos (README light/dark, generating the others) |
| `extension/icons/icon16/32/48/128.png` | toolbar and extension-page icon (square, transparent) |
| `extension/icons/logo-mark.png` | mark in the chat bar, popup and menus |
| `extension/icons/logo-wide-white.png` | white wordmark in the toolbar popup (dark background) |
| `installer/assets/luapilot.ico` | window, tray, installer and desktop shortcut icon |
| `installer/assets/logo_white.png` | white wordmark in the desktop app header (black background) |
| `installer/assets/wizard.bmp` (164x314) and `wizard_small.bmp` (55x55) | installer wizard images |
